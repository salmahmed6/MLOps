# Ride Duration ML Service

A production-oriented machine learning API for predicting ride duration.

The project demonstrates how to take an ML prediction workflow and expose it as a validated, tested, containerized REST API with structured logging and CI/CD automation.

---

## 🚀 Overview

The service provides a REST API built with FastAPI for ride-duration prediction.

It demonstrates several MLOps and production engineering practices:

- Python package structure
- FastAPI REST API
- Pydantic request/response validation
- ML model abstraction
- Structured JSON logging
- Request IDs
- Prediction latency logging
- Automated unit tests
- API tests
- Test coverage enforcement
- Code quality checks with Ruff and Black
- Docker containerization
- Docker Compose
- GitHub Actions CI/CD
- Docker image publishing
